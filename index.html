개념 2Biot 수와 내부저항

열은 매체 → 표면(외부 대류 저항) → 물체 내부(내부 전도 저항)의 순서로 직렬 저항을 지나갑니다. 실험실 1에서 다룬 직렬 열저항과 같은 구조입니다.

Bi = 내부 전도 저항외부 대류 저항 = L/k1/h = h·Lk

온도 분포 그래프의 괄호 두 개를 비교해 보세요. 표면에서 중심까지의 온도차(내부)와 매체에서 표면까지의 온도차(외부)의 비율이 저항의 비율, 곧 Bi를 따라갑니다.

  • Bi < 0.1내부저항이 매우 작아 물체 안의 온도가 거의 균일합니다. → 집중계(내부저항 무시) 해석 사용
  • 0.1 ≤ Bi < 40 정도내부와 외부 저항이 모두 중요합니다. → Gurney–Lurie 도표 또는 급수해 사용
  • Bi → ∞ (m → 0)외부저항이 무시됩니다. 표면 온도가 곧바로 매체 온도가 됩니다 (예: 응축 수증기).

개념 3Fourier 수: 무차원 시간

Fo = X = α tx₁² = 전도로 전달된 열의 속도저장되는 열의 속도

크기가 두 배이면 같은 Fo에 도달하는 시간은 네 배입니다. 그래서 두꺼운 고기는 얇은 고기보다 훨씬 오래 익혀야 합니다. Gurney–Lurie 도표의 가로축 X가 바로 이 값입니다.

    3단계온도, 시간, 전달된 열량

      연습집중계 문제

      유도내부저항이 있는 3차원 비정상상태 열전도 방정식

      정리좌표계별 형태 (k 일정)

      1. 직교좌표 (x, y, z): 평판, 직육면체1α∂T∂t = ∂²T∂x² + ∂²T∂y² + ∂²T∂z² + q̇k
      2. 원통좌표 (r, φ, z): 원기둥, 통조림1α∂T∂t = 1r∂∂r(r∂T∂r) + 1r²∂²T∂φ² + ∂²T∂z² + q̇k
      3. 구좌표 (r, θ, φ): 구형 식품1α∂T∂t = 1r²∂∂r(r²∂T∂r) + 1r² sinθ∂∂θ(sinθ∂T∂θ) + 1r² sin²θ∂²T∂φ² + q̇k

      의미식이 말하는 것

      1. 곡률이 온도 변화를 만든다1차원에서 ∂T/∂t = α ∂²T/∂x²입니다. 온도 분포가 아래로 오목하게 꺼진 곳(∂²T/∂x² > 0)은 양옆에서 열이 모여 데워지고, 위로 볼록한 곳은 식습니다.
      2. α가 클수록 빨리 반응한다α = k/(ρcp). 금속은 식품보다 α가 수백 배 커서 같은 크기라도 훨씬 빨리 온도가 고르게 됩니다.
      3. 특수한 경우정상상태이면 ∂T/∂t = 0 (실험실 1의 식), 발열이 없으면 q̇ = 0, 대칭 형상이면 r 방향만 남습니다.
      4. 무차원화하면 도표가 된다θ = (T−T∞)/(Tᵢ−T∞), Fo = αt/x₁², Bi = hx₁/k, n = x/x₁로 바꾸면 해는 θ = f(n, Fo, Bi) 하나로 정리됩니다. 이것을 그린 것이 Gurney–Lurie 도표입니다.

      실험곡률과 온도 변화: 유한차분으로 보는 열전도 방정식

      식을 격자로 바꾸면 각 점의 온도 변화는 이웃 두 점과의 차이로 결정됩니다: dTᵢ/dt ≈ α (Tᵢ₊₁ − 2Tᵢ + Tᵢ₋₁)/Δx². 그림의 점을 끌어 올리거나 내린 뒤 실행해 보세요. 화살표는 각 점이 데워지는지(빨강) 식는지(파랑)를 보여 줍니다.

      양 끝 온도는 고정 (표면 = 매체 온도, Bi → ∞)

      읽는 법Gurney–Lurie 도표 사용 순서

      1. 형상에 맞는 도표 고르기무한평판(양면 가열, x₁ = 반두께), 무한원기둥(x₁ = 반지름), 구(x₁ = 반지름). 한쪽 면이 단열된 평판은 x₁ = 전체 두께로 둡니다.
      2. 세 개의 무차원수 계산 m = kh x₁ = 1Bi,  n = xx₁,  X = α tx₁² n = 0은 중심, n = 1은 표면입니다. h가 매우 크면 m = 0입니다.
      3. 곡선 찾기도표는 n마다 한 묶음입니다. 해당 n 묶음에서 m 곡선을 찾습니다. m이 두 곡선 사이에 있으면 눈으로 보간합니다.
      4. 가로축 X에서 위로, 곡선에서 왼쪽으로세로축은 로그 눈금입니다. 0.1과 1 사이의 눈금은 0.2, 0.3 … 순서로 간격이 점점 좁아집니다.
      5. 온도로 환산Y = T∞ − TT∞ − Tᵢ  →  T = T∞ − Y (T∞ − Tᵢ) 시간을 구할 때는 거꾸로 Y를 먼저 계산하고 곡선에서 X를 읽은 뒤 t = X x₁²/α로 바꿉니다.

          원리왜 곱하면 되는가 (Newman의 법칙)

          유한한 물체는 무한한 물체들이 겹친 공간으로 볼 수 있습니다. 예를 들어 통조림은 무한원기둥과 무한평판이 겹친 부분이고, 직육면체는 서로 직교하는 세 무한평판이 겹친 부분입니다.

          θ(x, y, z, t) = θ평판(x, t) · θ평판(y, t) · θ평판(z, t),  θ통조림 = θ원기둥(r, t) · θ평판(z, t)

          3차원 열전도 방정식에 θ = X(x,t)·Y(y,t)·Z(z,t)를 넣으면 각 인자가 1차원 식을 따로 만족합니다(변수분리). 단, θ를 무차원 온도 (T−T∞)/(Tᵢ−T∞)로 쓸 때만 성립하며 다음 조건이 필요합니다.

          • 초기 온도가 균일하다
          • 모든 면이 같은 매체 온도 T∞와 같은 h에 노출된다
          • 물성이 일정하고 내부 발열이 없다

          각 방향의 m, n, X는 그 방향의 x₁(반두께, 반지름)로 따로 계산합니다. 도표에서 읽은 Y 값끼리 곱하면 됩니다. 온도 T끼리 곱하는 것은 틀린 방법입니다.
